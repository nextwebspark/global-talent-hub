What We Built
We added executive confidence scoring to your app — so when the LLM returns an executive, it also returns how confident it is that the person actually holds that role. This flows from the prompt → database → UI.

Change 1 — Database (Replit SQL Editor)
What: Added 2 new columns to the executives table.
Why: The database had nowhere to store confidence data before.
sqlALTER TABLE executives
ADD COLUMN IF NOT EXISTS executive_confidence text,
ADD COLUMN IF NOT EXISTS executive_confidence_reason text;
✅ Already done — you ran this successfully.

Change 2 — shared/schema.ts
What: Added the 2 new columns to the Drizzle schema definition.
Why: Drizzle needs to know the columns exist before TypeScript will allow you to read/write them.
The two lines added inside the executives table:
typescriptexecutiveConfidence: text("executive_confidence"),
executiveConfidenceReason: text("executive_confidence_reason"),

Change 3 — server/services/pipeline/types.ts
What: Added 2 new optional fields to the ExtractedExecutive TypeScript interface.
Why: TypeScript needs to know these fields exist on the executive object throughout the pipeline.
The two lines added:
typescriptexecutiveConfidence?: 'high' | 'medium' | 'low' | 'unknown';
executiveConfidenceReason?: string | null;
