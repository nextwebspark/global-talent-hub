FMCG distributors Saudi Arabia annual report official site revenue
Search 3 — News and trade press:

For each URL scored 1 or 2, fetch the full page content. Apply these rules:

If the URL is a company's own website: extract company name, description, revenue, employee count, executives if visible
If the URL is a news article: extract any revenue figures, employee counts, or executive names mentioned
If the page returns an error or is paywalled: skip it and move to the next URL
Maximum fetch 8 URLs per search to control costs

Part 4 — Database Merge Rules
When saving extracted data to PostgreSQL, apply these merge rules:

Manually edited fields are sacred — add a manually_edited_fields array to every company and executive record. If a field appears in this array, NEVER overwrite it from any pipeline run.
Confidence wins — if a field already has a value with confidence score X, only overwrite it if the new value has confidence score strictly greater than X.
Null fields always get filled — if existing value is null, always accept new pipeline data.
Executives are additive only — never delete existing executives. Only add new ones that don't already exist (match by name + company). Deletions are manual only.
Log every merge decision — create a pipeline_log table that records:

timestamp
company_name
field_name
old_value
new_value
decision (updated / kept / skipped)
reason (e.g. "kept: existing confidence 0.95 > new confidence 0.60")
